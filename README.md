# Jade

Public visual portfolio prototype for Jade | AI Solutions & Product Strategy.

Static HTML, CSS, and JavaScript. Project scenarios and mockup data are illustrative. The full multi-page website is in development.

## Single-page app

`index.html`, every route folder (`/work/`, `/blog/`, `/contact/`, `/work/<slug>/`, `/blog/<slug>/`) and `404.html` are copies of `tools/shell.html` (header + footer + `<main id="view">`) with per-route SEO meta, generated by:

    python3 tools/build-routes.py

`spa.js` is the router (clean URLs, no reload, fade/slide transition). Page bodies: `pages/*.html`; case studies and field notes: `data/content.json`; showcase projects: `data/showcase/<slug>.json`; per-route titles/descriptions: `data/routes.json`. Old `.html` URLs are small redirect stubs.
